# TEAM ARKA – AI Smart Logistics & Accessibility Intelligence Platform

> **Smart India Hackathon (SIH) 2026 Initiative**  
> *For a Connected Northeast India*

TEAM ARKA is an easy-to-use, fast, colorful, responsive, and lightweight AI-powered logistics and accessibility platform designed specifically for the unique terrain, weather, and transit corridors across all 8 states of Northeast India: **Arunachal Pradesh, Assam, Manipur, Meghalaya, Mizoram, Nagaland, Sikkim, and Tripura**.

---

## 🌟 Key Capabilities

1. **AI Route Optimization & Hazard Scoring**
   - Cascading State ➔ District/City selectors for seamless origin/destination input.
   - 8 vehicle categories: Bike, Car, Auto, Four Wheeler, Mini Truck, Lorry, Heavy Vehicle, Bus.
   - Comprehensive AI Route Evaluation: Route Score (out of 100), toll fees, signal timers, slope elevation safety, flood/landslide risk analysis, and alternative hill bypass routes.
2. **Interactive Northeast Digital Map**
   - Lightweight custom SVG vector digital map.
   - Real-time traffic overlays (Green = Low, Yellow = Moderate, Red = Heavy).
   - Traffic signals (`🚦 Signal 1 – 30s`, `🚦 Signal 2 – 45s`, `🚦 Signal 3 – 20s`).
   - Toll plazas (`🛣️ Madanpur Plaza – ₹120`, `🛣️ Nazirakhat – ₹85`).
   - Zoom-level decluttering (State Tier ➔ District Tier ➔ Local Roads Tier).
3. **Shipment Tracking & Telemetry**
   - 4-stage visual transit timeline: `Picked Up` ➔ `In Transit` ➔ `Near Destination` ➔ `Delivered`.
   - Driver profile, GPS coordinate mapping, and direct emergency call button.
4. **Disaster Emergency Mode (🚨 EMERGENCY MODE)**
   - 1-click critical incident dispatch.
   - Displays affected disaster zones, blocked mountain roads, active rescue corridors, and nearest trauma care centers.
5. **ARKA AI Assistant**
   - Speech-enabled voice assistant with *"Hey ARKA"* wake phrase activation.
   - Natural language route analysis and recommendations with interactive cards.
6. **Accessibility & Nearby Support Services**
   - Filterable directory: 24/7 Trauma Hospitals, Fuel Stations, Warehouses, Heavy Vehicle Repair Hubs, and Rest Areas.
7. **5 Regional Languages Supported**
   - Instant 1-click multilingual translation across **English**, **Hindi (हिन्दी)**, **Assamese (অসমীয়া)**, **Bengali (বাংলা)**, and **Manipuri (ꯃꯤꯇꯩꯂꯣꯟ)**.
8. **Fleet Analytics & Safe Admin Governance**
   - Lightweight CSS/SVG visualizations for monthly deliveries, transit delay factors, and vehicle utilization.
   - Safe administrative user log (credentials and passwords are strictly protected).

## 🛠️ Technology Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **UI Library**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Architecture**: Zero bloated 3D/animation packages; extremely fast and responsive (~146 kB bundle size).

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/sriganeshveeramasi-creator/AI-Smart-Logistics-Northeast-India.git

# Navigate to the project directory
cd AI-Smart-Logistics-Northeast-India

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
